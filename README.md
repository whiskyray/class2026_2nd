# 📚 수업 진도 관리 웹앱

학교 수업의 진도를 효율적으로 관리하는 모바일 친화적 웹앱입니다.

## ✨ 주요 기능

- 📅 **날짜 기록**: 수업을 진행한 날짜 입력
- 🏫 **반 관리**: 2학년(1-8반), 1학년(1-4반) 자동 분류
- 🕐 **교시 선택**: 1~7교시 중 선택
- 📄 **진도 추적**: 페이지 번호 입력
- 📝 **메모**: 수업 중 특이사항 기록
- 📊 **Google Sheets 내보내기**: CSV 형식으로 데이터 내보내기
- 🗑️ **데이터 관리**: 편집, 삭제, 필터링 기능
- 📱 **오프라인 지원**: PWA로 설치 가능하며 오프라인에서도 사용 가능

## 🚀 사용 방법

### 1. 웹에서 사용
- GitHub Pages에서 호스팅되므로 인터넷 브라우저에서 접속하면 됩니다.
- `index.html`을 브라우저에서 열거나, 리포지토리 설정에서 GitHub Pages를 활성화합니다.

### 2. 앱 설치 (모바일)

**iOS (Safari)**
1. 앱 바 아래의 "공유" 버튼 클릭
2. "홈 화면에 추가" 선택
3. 완료!

**Android (Chrome)**
1. 메뉴 아이콘(⋮) → "앱 설치" 또는 "홈 화면에 추가"
2. 완료!

**Desktop**
1. Chrome 주소창 오른쪽의 "설치" 아이콘 클릭
2. 완료!

### 3. 사용 방법

#### 기록 추가
1. 날짜, 학년, 반, 교시 선택 (필수)
2. 진도 페이지 번호 입력 (선택)
3. 특이사항 메모 입력 (선택)
4. "저장" 버튼 클릭

#### 데이터 필터링
- 날짜, 학년, 반으로 기록 필터링 가능
- 여러 필터를 함께 사용할 수 있습니다.

#### Google Sheets로 내보내기
1. "📊" 버튼 클릭
2. "확인"을 누르면 Google Sheets 새 문서가 열립니다
3. Ctrl+V (또는 Cmd+V)로 데이터 붙여넣기
4. 자유롭게 편집하고 관리하세요!

## 💾 데이터 저장

- **로컬 저장소**: 모든 데이터는 브라우저의 LocalStorage에 저장됩니다
- **오프라인 사용**: 인터넷 연결 없이도 데이터 추가 및 조회 가능
- **자동 동기화**: 연결 복구 시 데이터가 유지됩니다

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: LocalStorage
- **PWA**: Service Worker, Web Manifest
- **Export**: Google Sheets (CSV)

## 🎨 커스터마이징

### 색상 변경
`style.css`의 `:root` 섹션에서 변수 수정:
```css
:root {
    --primary: #4CAF50;        /* 메인 색상 */
    --primary-dark: #45a049;   /* 진한 메인 색상 */
    --secondary: #f44336;      /* 위험 색상 */
}
```

### 반 구성 변경
`app.js`의 `state.grades` 수정:
```javascript
const state = {
    records: [],
    grades: { '2': [1, 2, 3, 4, 5, 6, 7, 8], '1': [1, 2, 3, 4] }
};
```
